# MC 全版本下载器 v2.0.0

发布日期：2026-11-20

## 更新内容

- 新增 Minecraft Wiki 阅读器：搜索、内嵌阅读正文、浏览器打开、本地缓存
- 新增模组下载（Modrinth）：按游戏版本与加载器筛选，SHA-1 校验后写入 mods
- 新增外观设置：明亮 / 暗黑主题、5 种强调色、卡片透明度、毛玻璃，默认明亮主题
- 主题可即时切换，无需重启
- 修复侧栏提示卡片在小窗口下被裁切
