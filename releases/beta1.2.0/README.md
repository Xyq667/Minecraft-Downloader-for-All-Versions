# MC 全版本下载器 Beta 1.2.0

发布日期：2026-10-29

## 更新内容

- 新增 Java 运行时下载：支持 Java 8 / 17 / 21 / 25，从 Mojang 运行时清单逐文件校验 SHA-1 并解压
- 新增取消后清理：取消批量下载后可删除本次新增文件，只删本次写入内容并清理空目录
- 新增下载时间统计：实时计时，记录总耗时、流量、平均速度和最近 40 次下载记录
- 新增下载统计窗口，支持查看累计耗时、累计流量和平均速度
- 修复统计文件在版本升级时的迁移，旧版本设置与缓存随新版本目录同步
- 其他：启动器目录检测、加载器合并流程与进度显示同步优化

## 文件

- `MC全版本下载器.exe` — 主程序
- `MCVersionDownloader-beta1.2.0-source.zip` — 源码包

## 说明

- 加载器仅支持 Fabric / Quilt
- 与 Mojang / Microsoft 无关联，Minecraft 是 Mojang Studios 的商标
